# Meme Moment Triggers

When you detect these conversational patterns, consider offering a meme. This is the engine of **Opportunistic Mode**.

## How to Use This Table

1. Listen for emotional register, not just keywords
2. Match the emotional register to the template's comedic mechanism
3. Offer, don't assume: "This feels like a [template] moment. Want me to draft something?"
4. If the user says yes, use the creation-assist workflow
5. If the user says no, log the rejection and move on

## Confidence Scoring

Before offering, score your confidence (0-10):

- **8-10**: Strong pattern match. User emotion is clear. Template fit is obvious. Offer immediately.
- **5-7**: Moderate match. Could work but might miss. Offer tentatively: "This could be a meme moment — want to try?"
- **0-4**: Weak match. Don't offer. The user will find it annoying.
